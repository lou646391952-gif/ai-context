# ai-context

> 我的 AI 协作说明书 —— 换模型、换工具，不用重新介绍自己一遍。

## 这是什么

一份纯 Markdown 的个人上下文文档。任何 AI（ChatGPT / Claude / Gemini / Copilot / Cursor / WorkBuddy…）读完就能进入状态：知道我是谁、该怎么跟我说话、帮我做决策时按什么标准权衡。

## 它解决什么问题

- 每换一个模型，就要重新解释一遍背景和偏好
- 同一个纠正，要在不同工具里说好几遍
- 不同工具给出的输出风格忽好忽坏，全看运气

## 怎么用

1. 先完整读一遍 [AI-CONTEXT.md](./AI-CONTEXT.md)，核心规则 5 分钟能读完
2. 新开对话时，把文件内容或 raw 链接一起发给 AI
3. 同一个问题纠正两次以上，就回来改这份文件

### 启动语（复制这段）

```
请先完整读一遍我的 AI 协作说明，然后严格按其中的沟通规则、
决策准则和输出规范与我协作。
```

## 文件说明

| 文件 | 作用 |
|---|---|
| `AI-CONTEXT.md` | 主文档，给 AI 读 —— 规则层：怎么跟我协作 |
| `prompts.md` | 提示词模板库 —— 执行层：具体任务怎么开口 |
| `README.md` | 给人看，说明怎么用 |

两者的分工：`AI-CONTEXT.md` 管**长期基调**（语气、决策标准、输出规范），`prompts.md` 管**单次任务**（查票、比价、政策查询、写文档、让 AI 做工具）。

## 设计原则

- **规则化**：写"要做什么 / 不要做什么"，不写抽象的性格描述
- **短**：控制在 200 行内。太长的文档模型会跳过细节
- **可移植**：纯 Markdown，不绑定任何平台或工具
- **可演进**：每次被纠正都回写，让它越来越贴合实际
